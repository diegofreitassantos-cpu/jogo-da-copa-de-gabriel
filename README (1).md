# 🏆 Quiz Copa do Mundo

Quiz interativo sobre a Copa do Mundo, com interface gráfica feita em **Pygame**.

## 🎮 Como jogar

1. Instale o Pygame:
   ```
   pip install pygame
   ```
2. Execute o jogo:
   ```
   python copa_do_mundo_quiz.py
   ```

## 📋 Modos de jogo

- ⚽ **Modo Clássico** — história e curiosidades gerais
- 📋 **Grandes Placares** — maiores goleadas e resultados marcantes
- 🥅 **Artilheiros** — recordistas de gols nas Copas
- 🌍 **Países e Sedes** — seleções e edições do torneio

## ✨ Funcionalidades

- Perguntas de múltipla escolha (4 alternativas)
- Atalhos pelo teclado (A/B/C/D ou 1/2/3/4)
- Cronômetro por pergunta, com pontuação baseada no tempo de resposta
- Feedback explicativo após cada resposta
- Tela final com estatísticas, categoria de desempenho e curiosidades extras
- Visual moderno com animações simples

## 🎯 Objetivo

Testar seus conhecimentos sobre a Copa do Mundo de forma divertida, acumulando pontos e descobrindo curiosidades sobre o torneio.
